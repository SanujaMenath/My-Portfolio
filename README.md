# My Portfolio

Personal portfolio website of [Sanuja Menath](https://github.com/sanujamenath) - Full-Stack Developer & UI/UX Designer.

## Features

- Responsive single-page design with dark/light mode
- Animated skill bars with scroll-triggered animation
- Project showcase with tag-based technology display
- Contact form with EmailJS integration and inline validation
- Smooth scrolling and scrollspy active link highlighting
- Particle animation on the hero section
- SEO-optimized with Open Graph, Twitter Cards, and JSON-LD structured data
- Accessibility: skip-to-content link, ARIA labels, keyboard navigation, reduced-motion support

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid, Glassmorphism, Responsive design
- **Vanilla JavaScript** - Intersection Observer, DOM manipulation, ES6+
- **Font Awesome 6.5.0** - Icons (loaded non-blocking)
- **EmailJS** — Contact form delivery (no server required)

## Getting Started

1. Clone the repo:
   ```
   git clone https://github.com/SanujaMenath/My-Portfolio.git
   ```
2. Open `index.html` in your browser (no build step required).

### Customization

- **EmailJS**: To use your own email service, update the `publicKey`, `service_rf263jd`, and `template_7gvrrsj` values in `scripts/script.js`.
- **Profile image**: Replace `images/profile_image.jpg` (recommended: under 100 KB, WebP or optimized JPEG).
- **Content**: Edit section text directly in `index.html`.
